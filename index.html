url-is-the-site

This page is a loader. It takes a whole website packed into the part of the URL after the # and unpacks it right here in your browser.

You landed here with nothing after the #, so there is nothing to unpack yet. Try the demo:

open the demo page

pack your own

Paste any html below and get a link that contains all of it.

Nothing you type is ever sent anywhere. Browsers do not put the fragment in the HTTP request, so the server behind this page cannot see it. source on github
