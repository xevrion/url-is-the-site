url-is-the-site

Write a page, get a link with the whole thing inside it. Send the link to anyone and their browser rebuilds the page out of the address bar alone.

You can also just save this file and open it off your disk. It does not need a server, and neither do the links it makes.

open the demo page

write your own

Type any html you like in here. Hit the button and you get back a link with your entire page stuffed inside it. Copy it, paste it in a fresh tab, and watch your thing come alive out of nothing but the address bar.


Nothing you type is ever sent anywhere. Browsers do not put the fragment in the HTTP request, so the server behind this page cannot see it. source on github
